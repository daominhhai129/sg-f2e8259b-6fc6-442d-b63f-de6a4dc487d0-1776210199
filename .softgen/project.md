# Vision

Admin dashboard to let you manage your users and their digital business cards from a single, clean control center. You can see who your users are, how many cards they have, and quickly review or adjust their profiles.

# Design

--primary: 228 81% 56% (indigo blue for primary actions and highlights)  
--background: 210 40% 98% (soft light gray background for the app surface)  
--foreground: 222 47% 11% (dark slate for primary text)  
--accent: 174 63% 40% (teal accent for positive states and key highlights)  
--muted: 220 14% 96% (muted gray for sidebars, table headers, and secondary UI)

Headings use a slightly heavier weight for clear hierarchy, all in a modern sans-serif system similar to Geist/Inter. Layout is a left sidebar navigation, a top header, and a main content area with summary cards and tables.

# Features

- View an overview of key metrics like total users and total business cards.
- Browse users in a table with role, plan, status, and last active information.
- See how many digital business cards each user has.
- Prepare the UI for future features like editing cards, managing plans, and local persistence.
